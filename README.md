# 🛒 NewData

Sistema de tienda desarrollado con **ASP.NET Core MVC**, enfocado en la gestión de productos, autenticación de usuarios y control de roles.

Este proyecto forma parte de mi portafolio personal y demuestra el uso de arquitectura MVC, Entity Framework Core y SQL Server.

---

## 🚀 Tecnologías utilizadas

- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server  
- Razor Views  
- Bootstrap  

---

## ✨ Funcionalidades

- CRUD completo de productos  
- Registro e inicio de sesión de usuarios  
- Manejo de roles (Usuario / Administrador)  
- Vista de gestión exclusiva para administradores  
- Buscador de productos (vista pública y gestión)  
- Validaciones de formularios  
- Manejo básico de sesiones  

---

## 🔐 Roles

- **Usuario**: puede ver los productos disponibles.
- **Administrador**: puede crear, editar y eliminar productos desde la vista de gestión.

> El rol de administrador se asigna manualmente desde la base de datos por motivos de seguridad.

---

## 🧩 Estructura del proyecto

- **Controllers** → Controladores MVC  
- **Models** → Entidades del dominio  
- **Views** → Vistas Razor  
- **wwwroot** → CSS, imágenes y recursos estáticos  

---

## 🧪 Buscadores

- Buscador de productos en la vista pública  
- Buscador de productos en la vista de gestión (administrador)
